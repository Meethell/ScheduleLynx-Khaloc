# ScheduleLynx

ScheduleLynx is an application designed to help technical engineers or technical managers manage their technical work. The application offers the following features:

- **Task Management**: Organize and track daily technical tasks.
- **Ticket and Issue Management**: Record and resolve technical tickets and issues.
- **Equipment Management**: Control and monitor the status of all technical equipment.
- **File Management**: Manage documents and files related to technical work.
- **Customer Management**: Track and manage relationships with customers related to technical work.
- **Configuration Storage**: Store configurations and technical processes for bidding.
- **Team Collaboration**: Create connections and efficient coordination between team members.
- **Management and Reporting**: Help managers keep track of work progress and report results easily.

## Technologies Used
- **WPF**: (Windows Presentation Foundation) For building the user interface.
- **Entity Framework**: For managing database interactions using the ORM model.
- **Caliburn.Micro**: For efficient MVVM pattern implementation.
- **MaterialDesignColors and MaterialDesignThemes**: For using Material design components in the UI.
- **TCP/IP**: For communication and connection between different components of the application.
